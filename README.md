# About

This project implements an EDL grammer for tree-sitter.
Since the EDL compiler itself uses a hand-rolled parser, the parser generated by this is mostly used for syntax-highlighting in various editors.

# Installation In Helix

Since EDL is not really big enough to be recognized by editors like Helix, the tree-sitter needs some manual installation.
Add the following part to your `languages.toml` in your Helix config:

```toml
[[language]]
name = "edl"
scope = "source.eq"
injection-regex = "edl"
file-types = ["eq", "edl"]
comment-types = ["//", "///", "//!"]
indent = { tab-width = 4, unit = "    " }

[[grammar]]
name = "edl"
source = { git="https://github.com/LateinCecer/tree-sitter-edl", rev="..." }
```

For `rev` insert the id of the most recent commit.
Then, clone this repo any copy the files in the `queries` folder that end in `.scm` into the `runtime/queries/edl` folder of your Helix config.
For example, if Helix lives in `~/.config/helix` then you'd do

```bash
git clone https://github.com/LateinCecer/tree-sitter-edl.git
mkdir -R ~/.config/helix/runtime/queries/edl
cp tree-sitter-edl/queries/*.scm ~/.config/helix/runtime/queries/edl/
```

After that, fetch and update the grammar rules for Helix:

```bash
hx --grammar fetch
hx --grammar build
```
